# Investment-dial 研究線收線報告

**狀態**：收線（2026-09-09）  
**對象模型**：Qwen3.5-4B（bf16）  
**方法文獻**：Park et al. (2026), arXiv:2608.22852。本研究線著重重現其方法與因果機制，非針對論文特定數值進行複寫（詳見 §4）。

**核心結論**：在 Qwen3.5-4B 上，單神經元 investment dial 的控制機制成立且可被精確校準。透過細網格反推，三個目標立場之預測誤差均 ≤ 0.083，B 組 RMSE 達到 0.0579，且決策翻轉具備嚴格單向性與不可逆性。V1 階段之校準失敗，證實純粹為 A 曲線取樣解析度不足所致之假象（sampling artifact）。

**名詞定義**：

- **dial**：對單一 MLP down-projection 神經元施加之加性干預 Δ，用於連續調節模型整體的多空投資立場。
- **π**：在多空平衡證據協議下的立場指標，計算公式為 $(buy - sell) / (buy + sell)$，數值範圍落在 $[-1, +1]$。
- **Δ̂**：針對指定目標立場 $t$（網格包含 $\{-0.3, 0.0, +0.3\}$），由 A 組劑量響應曲線（transfer curve）反推所得之干預強度。
- **A / B 組**：自 427 家公司樣本池抽樣之兩組互斥公司集（各 85 家）；A 組用於干預劑量校準，B 組用於目標遷移再評估（reevaluation）。

## 1. 單神經元干預能實質誘發決策翻轉，且翻轉具備單向性與不可逆性

在同機 greedy 確定性解碼條件下，無干預狀態（δ=0）本身即構成直接的反事實基準，因此決策翻轉完全由神經元干預實質誘發，並非抽樣隨機雜訊：

- **A 組劑量響應（340 題 prompt）**：施加正向干預 Δ（0 至 2）時，共有 210 題（62%）由 sell 翻轉為 buy，期間反向翻轉（buy→sell）為 0，且各 prompt 隨干預遞增均無任何復歸現象（0/340，展現嚴格單調之閾值開關特性）。負向干預（δ=−0.25、−0.5）則全數呈現 buy 翻轉為 sell（分別翻轉 48 題與 85 題），反向亦為 0。
- **B 組目標校準翻轉（以 δ=0 無干預基線為對照）**：B 組在無干預時天生偏向空頭（141 題 buy / 199 題 sell，立場指標 π = −0.171）。當我們透過干預設定三個不同目標時，決策精確朝目標方向翻轉且無任何反向震盪：
  1. **要求更偏空頭（target = −0.3，負向干預 Δ̂ = −0.036）**：需比基線更悲觀，原本判定為 buy 的題目中有 **8 題被翻轉為 sell**（buy→sell：8 題，反向 0 題）；
  2. **要求拉回中性（target = 0.0，正向干預 Δ̂ = +0.180）**：需自偏空狀態推回多空平衡，原本判定為 sell 的題目中有 **38 題被翻轉為 buy**（sell→buy：38 題，反向 0 題）；
  3. **要求明確偏多（target = +0.3，更強正向干預 Δ̂ = +0.408）**：需大幅轉向多頭，原本判定為 sell 的題目中有 **83 題被大幅翻轉為 buy**（sell→buy：83 題，反向 0 題）。

## 2. 提升 A 曲線取樣解析度後三個目標全數達成，證實 V1 失敗純屬取樣瑕疵

V2 實驗採用 15 點組裝曲線並執行嚴格數值反推，成功將 B 組三個 target 之誤差壓制在 0.0824、0.0529 與 0.0215，綜合 RMSE 降至 0.0579，通過預先凍結之驗證門檻（RMSE ≤ 0.15、max residual ≤ 0.25，判定為 certified=true）。在相同神經元坐標與相同 B 組樣本下，V1 粗網格（5 個取樣點搭配三次多項式擬合）之 RMSE 高達 0.5757。自 V1 在 B 組之中性實測值回推，其當時施加之 Δ̂(0) 約達 +0.90，約為真實校準值（+0.180）的 5 至 6 倍。此結果證實粗網格完全錯失了 δ ∈ [0, 2] 區間之響應變化，導致擬合曲線嚴重失真（該數值為實測回推之描述性估計，非 V1 存檔欄位）。

## 3. 干預特性呈現閾值開關型態，高敏感度過渡區間集中於 Δ̂ ≈ −0.04 至 +0.41

A 曲線在 δ 0 至 2 之間的 π 變化，有 98% 集中在 δ ≤ 1.5 之內完成，當 |δ| ≥ 4 時已進入極端飽和狀態（±1.0）。三個目標立場對應之 Δ̂ 均落在 −0.036 至 +0.408 之間，且各 prompt 皆具備獨立的臨界翻轉閾值，越過即告定型。此種狹窄的過渡區間（僅約 1 個單位 δ 寬度）直接解釋了粗網格擬合必然失敗的幾何原因，亦意味著若欲實現更細緻的立場控制，必須依賴密集網格取樣。

## 4. 研究宣稱之邊界與未涵蓋之事項

- **B 組屬於重複評估（reevaluation）**：B 組樣本曾參與 V1 階段之候選神經元排序，本實驗證實的是校準機制在已知樣本集上的精確性，對完全未見之 86 家公司（`test` split）之泛化效力仍待驗證。
- **未配置對照神經元組（control-neuron arm）**：以 δ=0 作為反事實對照足以證實翻轉效應之存在，但若要確立「唯有此特定神經元具備此項專屬調節力」，仍須於後續評估階段引入對照神經元。
- **非對原論文數據之數值重製（numeric replication）**：基礎模型架構、公司樣本池與有效題目規模均與原論文不同，本地取得之 RMSE 0.0579 不宜與原論文之 0.038 進行直接的數值高低對比；原論文涉及之智能體環境、長文本組合與通用能力保留評估均非本線範疇。
- **神經元坐標未經全域重選**：本實驗沿用 V1 坐標，不主張此坐標為全域最優；dial 作用於模型全域投資立場先驗，不具備個別產業或單一企業之定向控制能力。
- **不展開跨模型橫向評估**：依據收線決策（2026-09-09），本研究線不進行跨模型之規模化掃描。

## 5. 收線判定：核心問題已獲解答，研究線正式收線

本研究線之核心命題「Park et al. (2026) 之單神經元投資立場調節機制能否在 Qwen3.5-4B 上重現並精確校準」，歷經三次實驗已獲得肯定結論，且 V1 階段之校準偏差亦已釐清並完成修正。線內已無未決實驗，本研究線正式收線。後續若有擴展需求，應開立獨立研究線並另訂版本協議：
1. 針對 `test` split 進行全新未見樣本之遷移驗證；
2. 針對特定產業進行條件化篩選之定向調節機制（sector-targeted dial）；
3. 引入對照神經元之特異性因果檢驗。
