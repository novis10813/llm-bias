# Investment-dial：單神經元連續調節整體投資立場（方法復現）

**狀態：已收線（方法復現）。** 模型為 Qwen3.5-4B（bf16）；2026-09-09 收線，V2 formal 校準通過（`certified=true`）。

**方法文獻：** Park et al. (2026), arXiv:2608.22852。本研究線重現其方法與因果機制，非針對論文特定數值進行數值複製。

**一句話發現：** 在受測模型與任務上，對 L15/N8490 單一 MLP 神經元施加加性干預能連續調節模型的整體買賣立場，細網格校準誤差壓至 0.0579，完成方法復現；但此調節作用於全域先驗，不等於能定向控制個別公司或產業。

## 1. 單神經元加性干預能否連續調節模型的整體投資立場？受測範圍內成立

我們在多空平衡證據的提示詞下，測量模型預測 buy 與 sell 的立場指標 $\pi = (buy - sell) / (buy + sell) \in [-1, +1]$。干預手段是在所有序列位置對第 15 層第 8490 號 MLP 神經元的 down-projection 輸出加上純量偏移 $\delta$。

**觀察：**
- **A 組劑量響應（85 家公司，340 題）**：正向干預（$\delta \in [0, 2]$）促使 210 題（62%）由 sell 翻轉為 buy，反向翻轉（buy→sell）為 0，且隨劑量遞增各題無復歸現象（0/340）；負向干預（$\delta = -0.25, -0.5$）促使 48 題與 85 題由 buy 翻轉為 sell，反向翻轉亦為 0。
- **B 組目標校準（另 85 家公司，340 題）**：無干預基線天生偏空（$\pi = -0.171$）。依 A 組曲線反推干預劑量後設定三個目標：
  1. **偏空目標（target = −0.3，$\hat{\Delta} = -0.036$）**：誘發 8 題 buy→sell，反向 0 題，實測 $\pi = -0.218$（誤差 0.082）；
  2. **平衡目標（target = 0.0，$\hat{\Delta} = +0.180$）**：誘發 38 題 sell→buy，反向 0 題，實測 $\pi = +0.053$（誤差 0.053）；
  3. **偏多目標（target = +0.3，$\hat{\Delta} = +0.408$）**：誘發 83 題 sell→buy，反向 0 題，實測 $\pi = +0.321$（誤差 0.021）。

**解讀：** 在 greedy 確定性解碼下，$\delta = 0$ 為直接反事實基準；翻轉展現單向性與單調開關特性，證實加性干預能有效操縱模型整體立場。

## 2. 為什麼 V1 粗網格失敗，而 V2 能成功校準？純屬取樣解析度不足

**觀察：**
- V1 採用 5 點取樣配三次多項式擬合，B 組綜合 RMSE 高達 0.5757；
- V2 改用 15 點細網格取樣與數值反推，B 組三個目標誤差壓至 0.082、0.053 與 0.021，綜合 RMSE 降至 **0.0579**，通過預先凍結的合格門檻（RMSE ≤ 0.15、最大殘差 ≤ 0.25，判定 `certified=true`）。

**解讀：** 曲線分析顯示，立場指標在 $\delta \in [0, 2]$ 間 98% 的變化集中在 $\delta \le 1.5$ 內完成，高敏感度轉換帶僅約 1 個單位寬度（$\delta \in [-0.04, +0.41]$），$|\delta| \ge 4$ 時已完全飽和（$\pm 1.0$）。V1 失敗純粹是粗網格錯失窄帶轉換區間造成的取樣瑕疵，並非單神經元調節機制失效。

## 3. 這項機制能否定向控制個別公司或特定產業？不能外推

**觀察與限制：**
1. **作用於全域先驗**：Dial 調節的是模型面對平衡財務證據時的整體多空傾向，無法針對特定單一公司或產業進行獨立操縱。
2. **B 組屬於再評估**：B 組樣本曾參與早期候選排序，本實驗確認的是已知樣本集上的校準機制，對未見過的 86 家公司（`test` split）泛化效力仍待檢驗。
3. **未配置對照神經元臂**：雖然無干預基線證實了翻轉效果，但尚未排除其他神經元是否具備同等或更強的調節力。
4. **非數值複製**：模型規模、樣本集與題目格式與原論文不同，本地 RMSE 0.0579 證實方法成立，不與原論文數值（0.038）做高低比較。
