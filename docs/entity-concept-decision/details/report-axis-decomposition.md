# L15 決策因果權重的成分分解：決策是「微小（0.5%）公司間差異」的高增益非線性讀出，不是低維局部線性軸

**run**:`phase1-v2-axis-decomp16-01`(`artifacts/qwen3.5-4b/entity-concept-axis-decomposition/runs/phase1-v2-axis-decomp16-01`,RTX 3060 12GB,bf16,32 層,seed 1729,1456 forwards,16 家公司,16m34s)。
**scientific_status**:`not_evaluated`。**purpose**:`development`。無正式 gate,描述性探查。
**上游**:`phase1-v2-stance-char16-01`(prompts + materials,stance 軸同公式)、2A `phase2a-gpu-bf16-01` prompts。

## 問題

[stance 軸因果探查](report-stance-causal.md)顯示 stance 軸是弱槓桿(5.5 倍公司間幅度只移 0.01 nats),而 2B 的完整狀態交換移 0.60 nats。**決策的因果力量在 L15 instruction 狀態的哪些成分上?** 本 run 把 L15 instruction-span 狀態對 margin 的局部因果權重分解到內容軸:8 個公司間差主成分(entity-contrast 子空間)、stance 軸、所有公司共享的均值方向、加 12 個隨機方向(對照＋整體權重估計)。

## 方法

- **介入**:L15 block 輸出後,把 `帶符號劑量 × unit 軸` 加到 instruction span,量答案位置 buy/sell margin 變化。
- **軸**:16 家公司狀態的前 8 主成分(張開公司間差)、stance 軸(同公式重 fit)、均值狀態方向(共享內容)、12 個 seed 隨機 unit 方向。
- **劑量**:±0.08(≈1 倍公司間距離)、±0.40(≈5 倍)。
- **整體權重 ‖w‖**:對隨機 unit 方向 r,E[(w·r)²] = ‖w‖²/2560,用 768 個随机方向測量估計。

## 結果

### 1. 16 家的 L15 instruction 狀態有 99.5% 是共享的

- 狀態范數 ≈ **10.0**(每 instruction-span 位置)。
- 公司間差異 ‖state_c − 均值‖ ≈ **0.052 = 狀態范數的 0.52%**。
- → 狀態被**共享內容**(相同證據＋相同 instruction)主導;公司身分(ticker＋名)只是 **0.5% 的差異**。

### 2. 決策的局部因果權重大、且分散

- **‖w‖ ≈ 12.9 nats/單位**(768 個随机方向測量;最大單筆占 2.3%,估計穩;小劑量回應更大,這是保守的局部權重下界級)。
- 內容軸佔 ‖w‖² 的比例:

| 成分 | 佔 ‖w‖² |
|---|---|
| 8 個公司間差主成分(entity-contrast 子空間) | **0.15%** |
| stance 軸 | **0.01%** |
| 共享均值方向 | **0.03%** |
| 結構化總和 | **0.18%** |

- → **99.8% 的局部決策敏感度在公司間差、stance、共享均值這些方向之外**。權重是**分散**的,不集中在任何一根內容軸上。

### 3. 個別內容軸的局部斜率(nats/單位;劑量上大致線性)

| 軸 | 斜率 | t |
|---|---|---|
| pc7 | −0.30 | −9.8 |
| pc1 | −0.25 | −8.3 |
| mean_state | +0.21 | +6.3 |
| pc5 | −0.19 | −5.6 |
| pc6 | −0.17 | −5.5 |
| stance | +0.13 | +3.6 |
| pc4 | −0.11 | −3.3 |
| pc8 | +0.08 | +2.7 |
| pc3 | −0.07 | −2.2 |
| pc2 | +0.05 | +1.9 |
| 隨機(12) | 均值 −0.006,sd 0.089 | (中心在 0,無結構) |

每根軸的斜率都小(相對於 ‖w‖=12.9),但有幾根統計顯著——**局部決策敏感度分散在多個小軸上**,不是單一根。

### 4. 讀出是**非線性**的(劑量上飽和)

- **隨機(非內容)方向**的每單位回應:@0.08 = 0.274、@0.40 = 0.086(**比值 0.31**)→ 推得越大、每單位越小,**飽和**。
- **內容軸**(狀態自然存在的方向):劑量上大致線性(比值 0.74–1.1)。
- → 決策讀出對「狀態自然不佔據的方向」的擾動**強非線性**;對「內容方向」大致線性。

### 5. 公司間的決策差異是**高增益非線性讀出**

- 局部線性讀出公司間差,預測的 margin spread ≈ **0.03 nats**(w 在公司間子空間的分量 0.50 × 公司間差異 0.052)。
- 實際公司間 margin spread = **1.66 nats**(均值 margin −2.30,16 家全 sell)。
- → 局部線性模型只捕捉觀察到的公司間決策差異的 **~2%**;其餘 ~98% 是**高增益、非線性/情境依賴**地讀出那 0.5% 的微小狀態差。
- **stance 軸的局部權重(0.13)× 公司間 stance spread(0.006)≈ 0.0008 nats**——無法用局部線性解釋公司間的 R²=0.605 相關。那個相關是**非線性/情境依賴讀出**的產物,不是局部線性槓桿。(因果探查的 0.10 與本 run 的 0.13 一致 → stance 的局部因果權重確鑿,只是小。)
- 2B 的狀態交換**不對稱**(朝好公司 IT→BLK +1.44、朝壞公司 BLK→IT +0.27)與這個非線性一致。

## 詮釋

1. **沒有乾淨的低維局部線性因果軸**能介導「公司身分 → 決策」。公司間內容在 L15 狀態裡只有 0.5%,決策以高增益、非線性地讀出它,背景是 99.5% 的共享內容。
2. **stance 是有用的描述讀數**(公司間決策 R²=0.605),但**局部因果槓桿小**(佔 ‖w‖² 0.01%、≈0.13 nats/單位)。它是「決策走向」的指標,不是「扳動決策」的把手。
3. **base-rate sell**(均值 −2.30、16 家全負)由**共享內容**設定(相同的證據被讀成偏賣),對所有公司相同;不是公司間差異。
4. 公司身分(ticker＋名)是 0.5% 的狀態差;它的決策效應**全部**在非線性讀出裡,不在任何局部線性軸上。

## 對介入/減偏的含義

- 推**單一線性軸**(stance 或某根公司間主成分)是**弱工具**(自然尺度下 ≤0.03 nats)。
- **完整狀態交換**有效(2B:0.60–1.44 nats),因為它一次沿很多方向移動狀態、進入非線性讀出。
- 要控制決策,得對**非線性讀出本身**下手,或在**公司間差異更大/更線性**的位置(更早層、其他 span、或答案位置狀態)介入。

## 限制

- 單層(L15)、單 span(instruction span)。
- **局部線性化**;劑量混合的 ‖w‖ 是量級性局部權重,不是精確線性模型(回應對劑量非線性、會飽和)。
- n=16;「公司間差主成分」是**這 16 家**的 entity-contrast 子空間,不是一般性的 entity-identity 子空間。
- margin 是單一答案位置,非多題平均。
