# Phase 1 V2 smoke-03：通用 stance 殘差化後，C 的「公司概念」訊號消失

**狀態：development／model_smoke，非正式 audit，`scientific_status=not_evaluated`。**run `phase1-v2-development-smoke-03`，manifest SHA-256 `5e7a78ead7aa2e23…`（前16位），三階段 complete，65 forward。本 run 在 smoke-01 基礎上新增**通用 stance 方向擬合＋正交化**：用評價對照行（E 家族的 PH−PL、NH−NL，跨兩概念共 8 對）擬出一個 general-stance 方向，再對每個候選方向做正交化，比較正交化前後「概念反應」與「評價反應」，以及四家公司的分數。

這是對 smoke-01 結論的**修正**，不是確認。

## 1. 核心發現：C 方向 88% 是 stance 軸

- **C 方向與 stance 方向的餘弦 = −0.883**（S = +0.772）。即 smoke-01 所見「客戶集中度」方向，絕大部分是通用正負評價軸，不是純概念軸。
- 正交化後：
  - C「概念反應」0.0222 → **0.0107**（掉到 random 帶內，約 0.01–0.03）。
  - C「評價反應」0.0655 → **0.0024**（按設計被移除）。
- **四家公司正交化後 C 分數全部塌到 ≈ +1.33，公司間 spread 僅 0.026（約 2%）。** smoke-01 裡 IT 0.088 / BDX 0.083 / NSC 0.060 / BLK 0.031 的公司間差異，正交化後消失。
- **鐵證**：smoke-01 的 raw C 公司分數排名（IT>BDX>NSC>BLK）與 sell 立場強度排名（依 margin：IT −3.18 > BDX −2.98 > NSC −1.90 > BLK −1.52）**完全同序**。raw C 分數追蹤的是賣出立場強度，不是客戶集中度。

## 2. 對 smoke-01 結論的修正

smoke-01 判讀「C 在 k=8 內 held-out 一致勝 random、具概念特異性」是**被 stance 混淆的假陽性**：

- C 各改寫家族的 P（集中）與 N（分散）句，除了概念不同，**語氣／隱含風險也不同**——模型把「集中」讀成風險（負 stance）。因此 88% 是 stance 的方向自然能把 P 與 N 分開，但那是靠 stance，不是靠「集中度」這個中立事實。
- 評價對照（E）的「固定評價看概念差」並**非真正控制住了 stance**：雖然明寫 favorable/unfavorable，模型對「集中」隱含的風險評價仍使 PH 比 NH 更不正面，故該比較混入了 stance。
- 正交化後殘留的「純集中度」反應 0.0107 落在 random 帶內，且公司間無差異。

## 3. 能與不能宣稱

- 能：**在固定 L15 k=8、本批 60 筆 AI 合成材料下，沒有證據支持存在一個與通用 stance 可分的「客戶集中度」公司相關概念。** k=8 子空間對這些「天生帶風險評價」的財務概念，主要承擔的是 stance／評價通道。
- 能（方法學）：本次 residualization 對照成功抓到 smoke-01 的 stance 假陽性——證明「只看 in-sample／held-out 勝 random」不足以宣稱概念特異性，必須再做通用 stance 正交化。
- 不能：(1) 非正式 audit、無統計功效、random 僅 16；(2) 材料為 AI 合成、未獨立人審；(3) 未證明「k=8 沒有任何公司概念」——只證明**在這些材料與此方向源下**沒有可分於 stance 的集中度訊號；(4) 未做決策因果。

## 4. 這代表什麼（研究層面）

「客戶集中度」在模型裡不是中立事實，而是**與風險／stance 綁定的評價**。因此「概念 → 決策」這段，在 k=8 裡實質上是「stance → 決策」。要找到真正公司相關、可分於 stance 的中間概念，必須：
1. 用**stance 平衡**材料（P/N 兩極寫成同等正面或同等中性，只改事實），讓 P−N 差不再含 stance；或
2. 換**方向源／層**，找不承擔 stance 的公司特異子空間；或
3. 接受在 L15 k=8 上，對這類天生帶評價的財務概念是 **null**。

## 5. 下一步（最便宜的決定性檢驗）

做一個 **2×2 控制設計**：集中度（高／低）× 明示評價（正面／負面）各 1 對，且正面／負面框架逐字相同、只改集中度數字。由此擬出「純集中度」方向（在固定評價下取差），驗證它 (a) 是否與 stance 方向正交、(b) 能否勝 random 分出 held-out 集中度對、(c) 四家公司在該方向上是否仍有可分差異。若仍弱，則 L15 k=8 對集中度為 null，轉評估其他方向源或概念。
