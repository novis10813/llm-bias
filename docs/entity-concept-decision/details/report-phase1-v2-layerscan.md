# Layer-scan 報告：公司概念是否在其他層級可從 stance 分離

**run**：`phase1-v2-layerscan-01`（`artifacts/qwen3.5-4b/entity-concept-layer-scan/runs/phase1-v2-layerscan-01`，RTX 3060 12GB，bf16，32 層，seed 1729，37 forwards 各捕捉 8 個層，bit-exact repeat 通過）。
**scientific_status**：`not_evaluated`。**purpose**：`development`。無正式 gate。

## 目的與設計

Round 1／Round 2 都顯示固定 **L15 k=8** 子空間是 stance 通道、不承載可分離的公司概念。使用者選了「掃描其他層級／維度」以決定原前提能否在別處救回。本 run 用更寬鬆的測試：**在每個候選層的完整狀態空間**（不做 k=8 限制） fitting 概念方向（G 地理多元、C 集中度）與通用 stance 方向，正交化後看四家公司是否分開。若某層在完整空間都分不開，任何子空間也不可能分開——所以這是決定性的寬鬆測試。

候選層（早→晚）：**L8、L12（entity handoff）、L15（instruction 峰值，round-2 基準）、L19／L20／L26（MLP-arm 神經元層）、L23**。每層：32 材料句 + 4 公司（IT/BDX/NSC/BLK）的 instruction-span 平均狀態。G 有真實世界公司順序（NSC 單一國家＝低，IT/BDX/BLK 全球＝高），是較強的公司可分性測試。

## 結果

### 核心：正交化後公司不分開（所有層）

stance 正交化後，四家公司在 G 與 C 兩個軸上都塌到幾乎相同的分數（ortho spread 0.004–0.038，極小）。範例（ortho 分數 IT/BDX/NSC/BLK）：

- L12 G：+0.76 / +0.76 / +0.76 / +0.76
- L15 G：+0.38 / +0.39 / +0.39 / +0.39
- L19 G：−0.58 / −0.57 / −0.57 / −0.57
- L26 G：+0.85 / +0.89 / +0.87 / +0.86
- L23 C：+0.23 / +0.23 / +0.22 / +0.21

**沒有任何一層**在移除 stance 後把 NSC 與其餘三家（或任何一對公司）分開。

### raw（移除 stance 前）

- **G**：四家公司 raw 分數本就幾乎相同（spread 0.005–0.036），**NSC 從不是 outlier**（皆排中間）。即模型在材料定義的 G 方向上，幾乎沒有編碼公司間的地理多元差異——任何層都沒有。
- **C**：raw 有微小梯度，但**精確追蹤 sell 立場強度**（margins IT −3.18 / BDX −2.98 / NSC −1.90 / BLK −1.52）。範例 L19 C：IT +0.330 > BDX +0.326 > NSC +0.314 > BLK +0.299，與 sell 強度同序；移除 stance 後塌掉。

### 兩個可拆開的觀察

1. **概念方向是「真的」但「不分公司」**：G／C 的 LO-group delta 在**每一層**都勝過 random q95（方向可泛化、非噪音）。但那個可讀方向指向的是「材料句 P 與 N 的差異」，四家公司沿著它（移除 stance 後）並不分開。可讀性（勝 random）≠ 公司可分性。
2. **完整空間比 k=8 更寬鬆，仍 null**：G 在完整空間與 stance 的餘弦只有 +0.09～+0.23（遠小於 k=8 內的 +0.62——k=8 限制放大了 stance 對齊）；C 在中後層 −0.42～−0.46。即便在這樣更寬鬆、stance 對齊更小的空間，公司仍不分開。

## 結論

1. **原前提在所有掃描層都不成立**：L8–L26 沒有任何一層承載「可從 stance 分離、且由材料方向辨識」的公司相關 G 或 C 差異。Direction A「公司狀態差子空間承載可獨立識別的公司概念」在 L15 k=8 與 L8–L26 完整空間皆被否決。
2. **模型是 stance 通道**：公司間的決策相關差異主要由 sell 立場強度驅動（C raw 精確同序 sell 強度），而非由可分離的概念內容驅動。這與 selective-intervention 已證實「L15 k=8 是因果有效的決策子空間」一致——那個因果有效子空間承載的是 stance，不是公司概念。
3. **方法學**：「勝 random 的可讀性」與「公司可分性」被再次清楚拆開；完整空間測試是最寬鬆的 null 測試（若完整空間不分開，子空間也不會）。

## 限制（誠實記錄）

- **材料定義的方向**：本測試問「材料定義的概念方向是否把公司分開」。若公司沿著**非材料方向**的 G 軸有差異（材料沒抓到），本測試看不見。一個更直接的幾何測試（NSC − mean(IT/BDX/BLK) 的規範與它對 stance／材料 G 方向的相關）能進一步拆開「公司根本不沿 G 差異」vs「公司沿非材料方向差異」；但 4 家公司只有 1 家國內（NSC）、其餘 3 家跨不同產業／規模（IBM 科技／BDX 生技／BlackRock 金融），「其餘 3 家」不是乾淨對照，該測試噪音大。
- **4 家、各一業**：跨產業統計力弱。
- 完整空間方向由 3 對材料句平均定義，較短；但 LO-group 已確認其可泛化。

## 對研究計畫的意義

三輪真實 smoke（round-1 C、round-2 G+C、layer-scan 7 層）一致指向：**Qwen3.5-4B 在這些財務概念上，用一個通用 stance／評價通道驅動 buy/sell 決策，而不把公司特定的財務屬性編碼成可從 stance 分離、可由材料辨識的獨立概念方向（至少在 L8–L26、這些材料與 4 家公司上）。** 這是對「找可解耦公司概念」路線的強 null，支持把研究問題轉向 **stance 通道本身**（模型如何把多種財務屬性壓成單一決策軸）。
