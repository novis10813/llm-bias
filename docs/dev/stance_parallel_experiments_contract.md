## Worktree and verification discipline

One owned writable branch per task, no edits to another worktree/sharedmain. Read-only data/thirdparty may be symlinked from main; dependencies remain pinned. Each slice writes a repository spec for new APIs, tests first, focused tests/uvlock/diff, commits only scoped files, and returns commit/path/results. Do not push, merge, submitGPU, install/updatepackages, stop processes or spawn nestedagent/workflow. Reviewers inspect exactbranchcommit, may execute scopedfakechecks only. Main verifies results and decides followup; pipeline code may enforce gates but never treats a missing agent result as success. Next wave builds method GPU runners from acceptedpieces; do not advertise these pure firstslices as completed research.
