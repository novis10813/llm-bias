# Baseline must bind the full plan before adapting generated outcomes

**Goal:** Define the next two bounded baseline integration slices: a full-population plan builder and a lossless generated-result adapter. Initial preflight required input-authority and malformed-result amendments; read-only re-preflight accepted this revision, including approved whole-pack hash reconstruction and existing generator-status compatibility. It is not a frozen research protocol or an executable GPU runner.

**Architecture:** Reuse `ExperimentPlan` and `GenerationOutcome`; consume the pinned `BaselineInputs` capability defined in `stance_baseline_inputs_spec.md`. Keep plan construction tensor-free. Import generation types only in the separate adapter module.

## 1. Scope stays below the model runner

In scope: exact 2012 baseline keys, input-identity checks, explicit certification requirements, and conversion of existing plain/Harmony results into executed rows and no-op inputs. Do not implement model loading, inference orchestration, a CLI, checkpoint policies, transient activation capture, persistence, metrics, or GPU submission. Do not edit accepted core contracts or historical artifacts. B0 implementation and independent acceptance must finish before either slice dispatches.

## 2. Existing contracts supply the integration boundary

【已驗證: `llm_bias/core/experiment_contract.py:ExperimentPlan`】 Plans copy and sort unique keys and gates; their hash covers identity, keys and gate names. `keys_for_shard(index,count)` uses deterministic full-key hashing. Operator/parent `not_applicable` is legal only for baseline arms.

【已驗證: `llm_bias/core/experiment_contract.py:GenerationOutcome`】 Failed generations have null primary decisions, can retain legal diagnostic flags, and require the registered finish/failure pairing. `ExecutionRow` enforces matching ticker, condition and trial. The accepted F1 vocabulary contains nine causes, including `unsupported_tokenizer` with finish `unsupported`.

【已驗證: `llm_bias/core/inference/structured_output.py:StructuredGenerationResult`】 Both generation drivers return this type. It retains complete continuation IDs/text, payload, decision/reason, flags, finish/failure, elapsed time and defensive provenance. Persist through `to_dict()`, not `dataclasses.asdict()`.

【已驗證: `llm_bias/core/prompt_input/decision_prompt.py:render_decision_prompt`】 `template_sha256` covers body/entity templates and instruction only. `wrapper_policy` also records wrapper arguments and the actual tokenizer chat template. A future execution manifest must bind these separately; the bare body-template hash cannot certify wrapper identity.

## 3. New contracts reject narrower plans and repaired failures

**REQ-B1.1 — Construct only the complete baseline plan.** 【新設計】 `build_baseline_plan(inputs: BaselineInputs, identity: PlanIdentity) -> ExperimentPlan` verifies that identity population/issuer/roles/evidence hashes equal the input capability's membership/issuer-mapping/roles/raw-evidence hashes. Require operator and parent hashes to be `not_applicable`. Generate one `RowKey(stage="baseline", ticker=pair.ticker, condition=pair.condition, trial_id=pair.trial_id, arm="baseline", dose="0")` per approved pair, exactly 2012. No caller stage, cohort, ticker, role, gate or count overrides. Gate names are exactly `("input_integrity", "model_binding", "no_op", "protocol_frozen")`; construction does not set their truth values. A hash-shaped identity is not proof that its protocol/model claims are true.

**REQ-B1.3 — Revalidate directly constructed bundles against approved bytes.** 【新設計】 `BaselineInputs` is a public trusted container, not factory attestation. B1's private `_validate_baseline_inputs(inputs)` must reject non-BaselineInputs objects and mutable/non-record member/pair collections; require tuples of known frozen PopulationMember/EvidencePair/EvidenceItem scalar-string records, 503 members and 2012 pairs. Reconstruct canonical bytes without sorting or normalization: manifest and roles exports as `canonical_json_bytes(value) + b"\n"`; population as `{"members": [asdict(member), ...], "source_sha256": manifest["population_source_sha256"], "membership_sha256": inputs.membership_sha256}` plus newline; evidence as concatenated canonical asdict pair lines, each with newline. Require manifest reconstructed SHA and inputs.manifest_sha256 equal the approved literal `b3ee1d47990c9becce37e2eafe4739b9ab1d2544894e3fdfe5febec77819168d`; require reconstructed three payload hashes equal this pinned manifest's output_hashes. Recompute member-list and issuer-mapping semantic hashes and match both bundle fields and pinned manifest semantic hashes; match roles_sha256 to manifest roles_hash and recomputed roles assignment_hash, and evidence_sha256 to the reconstructed raw JSONL hash. Counts or self-consistent caller hashes alone are insufficient: a full-sized forged evidence pack can satisfy those checks. Convert malformed export/type/serialization conditions to ValueError without returning a partial plan. This validates byte equivalence to the approved pack, not where the object was constructed; an exact defensive copy is acceptable. B1 may import tensor-free artifact_paths/population/stance_evidence helpers. No filesystem writes or fresh temporary materialization are required.

**REQ-B1.2 — Keep unbound policy claims outside certification.** 【新設計】 The builder copies the supplied validated identity without inventing protocol, model, code, backend, generation-policy, schema or template hashes. A later manifest compiler must derive those from concrete approved records, including wrapper/chat-template identity, grammar/channel policy and checkpoint revision. No runner may claim these gates passed merely because B1 constructed a plan. Before formal freeze, any gate or design change creates a new plan identity.

**REQ-B2.1 — Convert without reinterpretation.** 【新設計】 `baseline_execution_row(plan: ExperimentPlan, inputs: BaselineInputs, key: RowKey, result: StructuredGenerationResult) -> ExecutionRow` rejects a foreign key, non-baseline arm/stage/dose, changed input identity or malformed typed result. Use the input mapping for issuer ID. Copy decision, three completion flags, finish and failure exactly into `GenerationOutcome`; do not reparse text, coerce booleans, clear a forged decision, remap a cause, or discard failed rows. Unknown/inconsistent returned states raise `ValueError`; they do not become fabricated executed exceptions. Genuine generation failures remain executed rows.

**REQ-B2.3 — Validate a typed result before either conversion.** 【新設計】 Both adapters use a private `_validate_generation_result(result)`; StructuredGenerationResult's constructor itself does not validate fields. Require that type, a tuple of genuine nonbool Python token integers in `[0, 2**63-1]`, and generated_token_sha256 equal `sha256_json(list(result.generated_token_ids))`. Require generated_text/json_payload strings encodable as strict UTF8; elapsed_seconds must be nonbool int/float, finite and nonnegative. Require reason/error_message/decode_error to be None or strict-UTF8 strings. Successful results require a nonblank reason, no decode_error, and no error_message; failed results require reason=None, retain optional diagnostic error strings and legal flags unchanged. Validate three genuine boolean flags, legal buy/sell/null decision, known finish/failure and their exact pairings by constructing a temporary GenerationOutcome with fixed nonblank synthetic identity strings and condition `++`; do not import private failure enums or duplicate their logic. Require private provenance storage to be bytes containing a strict duplicate-free, nonfinite-free JSON object whose bytes equal canonical_json_bytes of that object (no terminal newline). This checks structural integrity only; it does not certify claimed model/backend provenance, reconstruct token decoding, or reparse the payload. Empty IDs/text are legal on genuine failed execution; a successful result requires nonempty IDs/text/payload. No coercion or repair.

For row conversion, revalidate the entire input bundle through B1's builder and require the rebuilt baseline plan to equal the supplied plan's canonical export before checking key membership. Caller violations, forged result states and foreign keys raise ValueError; they never become executed failures. A correctly formed result bearing any registered generation failure converts losslessly to an executed failed row.

**REQ-B2.2 — Preserve the no-op comparison input.** 【新設計】 `baseline_gate_input(result: StructuredGenerationResult) -> GateGenerationInput` copies the complete continuation IDs and generated text, decision, flags and cause. Validate the same outcome-status invariants using a private shared helper, and pass existing signed-int64/UTF8 validation. In particular, Harmony analysis and final headers remain in these IDs/text; do not substitute final JSON IDs or buy/sell readout tokens. Failure with otherwise identical output still fails the existing pure gate. Neither adapter returns eligibility or writes files.

Example 【新設計】: a result with `decision=None`, `failure_type="unsupported_tokenizer"`, `finish_reason="unsupported"` becomes an executed failed row with that exact cause. A result with that cause and `decision="buy"` raises rather than being repaired.

## 4. Each slice has its own acceptance boundary

### B1 delivers a tensor-free full-plan builder

Create only `llm_bias/core/stance_baseline_plan.py` and `tests/test_stance_baseline_plan.py`. Consume accepted B0 and the existing plan contract; produce REQ-B1.1/B1.2/B1.3. Use temporary approved full-pack copies and visibly synthetic non-input identity hashes. Tests verify all 2012 keys, all roles retained, plan JSON roundtrip, deterministic disjoint shard union including empty shards, four identity mismatches, forbidden operator/parent values and isolated import safety without torch/transformers. Include directly constructed or dataclasses.replace bundles with empty/truncated/duplicate/foreign pair tuples, wrong hashes, altered role exports, mutable collections and full-count evidence modifications with self-consistent caller hashes; all must reject. An exact copied approved bundle must pass. Tests must not label synthetic identities certified.

Red: missing builder import or failing full-plan assertions. Green: implement the minimum builder, then run `uv run pytest -q tests/test_stance_baseline_plan.py tests/test_stance_baseline_inputs.py tests/test_stance_contract.py`. Independent acceptance precedes commit and B2 dispatch.

### B2 delivers the generated-result adapter

Create only `llm_bias/core/stance_baseline_adapter.py` and `tests/test_stance_baseline_adapter.py`. Consume accepted B1 and existing generation/gate records; produce REQ-B2.1/B2.2/B2.3. Use deterministic tensor-free synthetic results for both successful decisions and all nine failures, including legal diagnostic flags and complete Harmony envelope IDs/text. Add mutations for bad finishes, unknown failures, non-null failed decisions, forged boolean fields, foreign keys and input identity mismatches. Also test mismatched token hashes, bool/out-of-range tokens, mutable token lists, negative/nonfinite/bool elapsed time, invalid UTF8 strings, failed non-null reasons, successful blank reasons, malformed/noncanonical provenance bytes and forged/truncated plans. Test allowed failed empty-output and diagnostic-completion states separately from successful nonempty-output requirements. Assert raw field equality, executed-failure progress accounting and false no-op gates; no checkpoint is needed.

Red: missing adapter or failed lossless-mapping assertions. Green: implement, then run `uv run pytest -q tests/test_stance_baseline_adapter.py tests/test_stance_baseline_plan.py tests/test_stance_contract.py tests/test_stance_gates.py`. Independent acceptance precedes commit.

For each slice, also run `uv lock --check`, `git diff --check` and thread-bounded `uv run pytest -q`. Record timeouts separately from passes. Main verifies before dispatching the dependent slice.

## 5. The execution harness needs separate specifications

The next runner design must derive concrete manifests, dispatch plain/Harmony generation, manage external scoped hooks with cleanup, capture self-replacement source only transiently, and register every shard with exact resume coverage. No-op certification must cover the pre-registered model/site/scope/cache configurations; a first-key check cannot stand in for unspecified coverage. Those designs are outside these two slices and must pass their own preflight before implementation.

## Audit skeleton

Core claim: baseline integration preserves the approved full population and the generator's exact failure cause. Support: full-plan identity binding, lossless row conversion, complete-output gate conversion. Certification and model execution require subsequent independently specified evidence.
