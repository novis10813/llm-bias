# LC2 executes genuine donor-to-target generation without exporting residuals

**Goal:** Execute one explicitly aligned cross-prompt replacement using the accepted schema drivers, transient capture and unchanged scoped replacement hook. Parent matching detects clean-generation drift; it does not certify model authenticity or replace phase-level no-op gates.

## 1. Only the three-arm execution primitive is in scope

Create `llm_bias/core/inference/stance_localization_execution.py` and `tests/test_stance_localization_execution.py`. Do not modify accepted drivers/hooks/capture/alignment/parent, model loader, historical artifacts or dependencies. No pairing, layer selection, persistence, GPU checkpoint loading or eligibility promotion. Both plain JSON and native Harmony routes must preserve complete continuations.

Grounding: 【已驗證: inference/stance_noop_execution.py:execute_prompt_noop】 shows grammar/model/tokenizer/prompt validation and fresh tracker per real driver call. 【已驗證: inference/stance_transient_capture.py:capture_prompt_residual】 original tracker may end while capture lifetime stays open for replay. 【已驗證: core/stance_localization_alignment.py:SpanAlignment,build_span_alignment】 immutable ordinal maps separate donor coordinates from target labels. 【已驗證: core/stance_baseline_adapter.py:baseline_gate_input】 validates complete result integrity. 【已驗證: inference/stance_noop_execution.py:_diagnostics】 defines validation of exact compact replacement diagnostics; LC2 reuses this helper without changing it. REQ references below are new designs, not existing APIs.

## 2. Preflight checks fail before any model generation

**REQ-LC2-1 【新設計】** API:

```python
execute_prompt_replacement(model, tokenizer, donor_prompt: DecisionPrompt,
    target_prompt: DecisionPrompt, capability, *, policy: StructuredGenerationPolicy,
    layer: int, hook_site: str, alignment: SpanAlignment,
    expected_donor: StructuredGenerationResult,
    expected_target: StructuredGenerationResult, verified_binding=None
) -> PromptReplacementExecution
```

No zero-vector argument; no claim of a no-op gate. Model/grammar/tokenizer/route/policy bind with the same actual helper checks used by NO1, including native Harmony suffix and signed integer prompt bounds. Prompt IDs come from these DecisionPrompt records and are materialized on the actual input embedding device (resolve `model.hf_model.get_input_embeddings().weight.device`). Require callable get_input_embeddings returning a module with a finite floating two-dimensional weight and positive width/rows; prompt IDs must lie inside both the input-embedding row count and the output head range. New CPU fakes extend the existing fixtures with a real torch.nn.Embedding-backed accessor; the original NO1/Harmony fakes do not provide it. Reject invalid embeddings, unverified factory capabilities, wrong policy route and invalid layer/site before generation. Both prompt schema hashes equal the nested capability schema; actual wrapper records and template hashes must match one another (donor/target text and length may differ). Recompute `build_span_alignment` from supplied prompts/span/policy/selector and require exact mapping record equality; never trust a forged constructor map. Validate both expected results through `baseline_gate_input` and explicitly require its `primary_valid is True`. Expected-result provenance must match schema_sha256, schema_bytes_sha256, tokenizer_sha256 and head_vocab_size of the nested capability; stop_token_ids must equal list(nested.stop_token_ids), generation_policy must canonically equal asdict(policy), hf_controls must equal the driver's `_hf_controls(policy, nested.stop_token_ids)`, and generation_policy_sha256 must equal sha256_json({'policy': asdict(policy), 'hf_controls': controls}). Model_binding and mask_backend are incidental device/binding records and are not full-dict comparison fields. These checks bind recorded configuration, not prompt authenticity. Invalid parent rows are excluded before this primitive by the future pairing plan, not fabricated as donor observations.

**REQ-LC2-2 【新設計】** Enter a fresh tracker context first, then the transient capture context (which requires an active tracker); run actual donor generation inside both with capture of `alignment.donor_capture_positions` at the declared layer/site. Exit its tracking scope before recipient replay but keep capture lifetime open. Validate actual result structurally. If donor fails, return status donor_failed with only actual donor present. If the REQ-LC2-6 full-output comparison differs from expected donor, return donor_mismatch (elapsed time is deliberately ignored); never inject its residual. Compare all full continuation IDs including Harmony analysis/envelope. If successful exact matching donor has unavailable capture, return source_unavailable. Preserve actual results and diagnostic mismatch fields; do not fabricate control results.

**REQ-LC2-3 【新設計】** With capture alive and original tracker inactive, run clean target generation under a new tracker, with no intervention. If it fails, return target_failed with actual donor and target_clean only. If complete generated output differs from expected target under the same comparison, return target_mismatch. This extra generation checks donor-capture cleanup does not affect the target; baseline identity matching is not itself zero/self gate. No failed/mismatched target is patched.

**REQ-LC2-4 【新設計】** Gather `holder.require_source()[:, alignment.source_indices, :]` transiently; do not save raw source/gathered tensor, convert precision or interpolate. Gathered rows correspond to target positions. Run target generation with another fresh tracker and unchanged `scoped_residual_intervention(operation='replacement', scope='prompt_only', source=gathered, source_positions=alignment.target_positions, prompt_positions=alignment.target_positions, dose=1)`. Keep captured donor hooks inert during both recipient calls. Preserve actual returned intervention result even when it failed; return status executed and exact scalar replacement diagnostics. Failure is a generation outcome, not an omitted row or an excuse to resample. Drivers already encode genuine runtime failures; caller/preflight/helper errors may raise and cleanup must still run. Always release hooks/source references on return/exception; no persistent activation cache.

## 3. The result validates absence as well as presence

**REQ-LC2-5 【新設計】** Frozen `ReplacementMatchChecks(donor: bool, target: bool | None)` validates genuine bools and exports a fresh two-key dict. Frozen `PromptReplacementExecution` requires fields `status: str`, `donor: StructuredGenerationResult`, `expected_donor: StructuredGenerationResult`, `target_clean: StructuredGenerationResult | None`, `expected_target: StructuredGenerationResult`, `intervention: StructuredGenerationResult | None`, `match_checks: ReplacementMatchChecks`, `alignment: SpanAlignment`, `_diagnostics_bytes: bytes | None = None`. Both expected outputs are required in every state and must be primary-valid. No redundant expected-token-hash fields: their integrity-checked full outputs already contain hashes. Properties: `executed` is status=='executed'; `diagnostics` parses bytes into fresh JSON via `_diagnostics(raw, 'replacement')`, or None. `to_dict()` exports exactly status/executed, donor/expected_donor/target_clean/expected_target/intervention via result.to_dict() (or None for absent actual arms), match_checks/alignment and parsed diagnostics; no private bytes.

Status enum exactly donor_failed/donor_mismatch/source_unavailable/target_failed/target_mismatch/executed. Validate all actual outputs structurally. Recompute match_checks against stored expected full results with REQ-LC2-6 and reject supplied bool disagreement; target check is None iff no clean target attempted. donor_failed iff donor has failure and no later outputs/diagnostics; donor_mismatch requires valid donor and false donor match, no later outputs; source_unavailable requires valid matching donor, no later outputs. target_failed/target_mismatch/executed require a valid matching donor and target_clean present. target_failed requires target failure and no intervention/diagnostics; target_mismatch requires valid target, false target match and no intervention/diagnostics. executed requires matching valid donor/target, an actual intervention (may fail), and exact replacement diagnostics. No other combination is legal. For diagnostics, selected_token_opportunities <= len(alignment.target_positions)*(1+len(intervention.generated_token_ids)); this is a loose upper bound for normal full-prompt recomputation, not equality. Cache true normally observes one selected-token set; lower counts from fake bypasses or early failures remain representable. Complete text-only mismatch with identical token hashes must remain representable and fail the match. No opaque config hash makes result self-certifying; validation is integrity only.

**REQ-LC2-6 【新設計】** Complete-output equality compares token tuple, generated text, JSON payload, decision, primary reason, three flags, finish reason, failure_type, error_message and decode_error; ignore elapsed_seconds and do not compare incidental entire provenance dict values beyond preflight config binding. Capture/result source availability is not formal research eligibility. Consumer computes toward-source ITT with fixed planned baseline denominator later; this primitive does not infer effect or calculate primary statistics.
