# Cache-aware interventions and fail-closed no-op spec

Goal: intervention scope describes absolute prompt/decode positions, not `sequence_length == 1`; real intermediate MLP additions and no-op identity must gate every research phase. Unit tests precede real checkpoint checks.

## Grounded interfaces

Verified `llm_bias/core/inference/interventions.py:residual_interventions` installs post-block transforms before its cleanup try/finally; a later invalid layer or registration exception can leak an earlier hook. mid_residual_interventions has the same installation-before-finally defect; pre_residual_interventions and record_block_states protect installation. Preserve public behavior while fixing both post/mid lifecycle defects.
Verified `mlp_addition.py:mlp_addition` edits true dense down_proj input, all positions including cached decode, and returns early for zero scalar. `mlp.py:dense_down_projection` rejects architectures without hookable dense down_proj, including unsupported routed MoE. Preserve legacy all-position behavior.
Verified model generation uses `model.hf_model`; decoder layers resolve via model.layers. HF kwargs may expose cache_position, position_ids, input_ids, inputs_embeds and past_key_values. Real architecture metadata paths must be validated separately; no guessed routing or normalization writes.

## Requirements (new contracts except lifecycle fix)

REQ-H1: fix residual_interventions and mid_residual_interventions installation cleanup by placing each whole registration loop within try/finally. Tests cover later invalid layer, failed second registration, forward transform exception and normal exit; pre/mid transform semantics remain unchanged.

REQ-H2: new `GenerationPositionTracker(prompt_length, use_cache)` records batch-one absolute token positions from a root HF model forward pre-hook inspecting positional args[0] and kwargs input_ids/inputs_embeds. Resolve root via explicit hf_model, then _hf_model, then bare nn.Module; verify hookability, never infer architecture from slug. Explicit cache_position (1D) or position_ids (1×seq) is authoritative after checking consistency, unique nonnegative integer positions, length matching forward input. When no position metadata exists: no-cache full input uses arange(seq), requiring seq>=prompt_length; initial empty/no past cache full prefill uses arange(seq), requiring seq==prompt_length. With nonempty past cache, derive offset ONLY from a validated get_seq_length() return or recognized legacy tuple/list of layer key/value pairs whose first key is a rank4 tensor [batch,heads,seq,head_dim], sequence axis2, batch1, consistent nonnegative lengths across layers. Empty tuple means empty cache only on full initial prefill; all other layouts are unsupported. Reject bool/nonint/negative get_seq_length returns; if no reliable cache length exists, raise UnsupportedPositionMetadata before edits. Explicit chunked cache_position is supported, including a one-token prefill chunk at position 0. Do not infer decode from sequence length or maintain guessed counters. Require tracker fresh per generation, no global state; no masks/caches serialized. Each layer/MLP consumes the same active root positions and checks hidden sequence length. Reject mismatched position_ids/cache_position, missing root tracking context, batch>1 and shape mismatches.

REQ-H3: scope literals `prompt_only`, `decode_only`, `prompt_and_decode`; optional explicit unique prompt_positions within [0,prompt_length). prompt_only selects those original prompt positions on every no-cache recomputation; it never edits newly generated positions. decode_only selects positions>=prompt_length. prompt_and_decode unions selected prompt and all decode positions. instruction-only is prompt_only with registered instruction positions. This semantics is independent of cache flag; each tensor token index maps to absolute position. Numeric dose finite, direction dimensions exact, no silent layer wrap/position clipping.

REQ-H4: add keyword-only optional position selector to real `mlp_addition` while preserving legacy call signature/default all-position behavior. Keyword `selector` callable signature is selector(values: torch.Tensor) -> Sequence[int] | torch.Tensor. It returns a 1D bool tensor of exactly sequence length (move safely to values.device) or a unique Python integer sequence in [0,seq), rejecting bool/negative/duplicate/out-of-range indices. Empty selection returns input unchanged, no clone/arithmetic. Selector is driven by tracker; no DIM-selected static weight substitute. Scalar modifies only neuron coordinate at selected positions before actual dense down_proj. Validate invalid coordinate even at zero; zero performs no floating arithmetic. Dense norm effects are naturally downstream; routed GPT-OSS neuron remains unsupported unless later true routed hook is implemented. New scoped residual context in `core/inference/stance_interventions.py` uses tracker and existing pre/post residual hooks, with same absolute selection for vector addition, projection ablation and source prompt replacement. Shared vector [d_model] and finite scalar, source/target positions explicit; donor tensor transient and supplied only for original prompt. Exact alignment passed explicitly; never nearest by default. Projection ablation x - ((x·u)/(u·u))*u at selected tokens; reject zero/nonfinite vector. Replacement zero/self preserves tensor values without avoidable cast changes. No training/basis logic here.

REQ-H5: compact perturbation diagnostics count modified token opportunities, norm summaries, residual-relative norms and hook site/scope; never retain/serialize activation arrays. Any delta tensors are transient within callback and reduced immediately. Cleanup must remove root/layer/MLP hooks after errors and reset active tracker in enclosing context finally (post-hook alone is insufficient when root forward raises). Do not persist source capture or KV cache.

REQ-H6: pure no-op gate consumes independent `GateGenerationInput(token_ids: tuple[int,...], text: str, decision: str|None, schema_complete: bool, reason_valid: bool, decision_complete: bool, failure_type: str|None)` defined locally, no import from unfinished schema module. `evaluate_noop_gate(baseline, repeated_baseline, zero_addition, self_replacement, *, config_hash: str) -> NoOpGateResult(passed: bool, config_hash: str, checks: dict[str,bool], diagnostics: dict[str,JSON scalar/list])` validates 64hex config hash, nonempty generated sequences and primary validity, returning compact comparisons/token hashes/counts without token arrays. It consumes complete output token sequences and structured validity/decisions for repeated baseline, zero addition and self replacement. All token sequences must be exactly identical; separately record decision/schema/text identity diagnostics and hashes. Different reasons with same decision FAIL token identity, even full mode. Failures preserve diagnostics but prevent eligible results at baseline/localization/method/comparison stages; no smoke-only exception. Empty or invalid baselines cannot pass identity merely because repeated failure matches. This is a strict proposed gate, not a claim real checkpoints meet it. Cache/kernel/precision variations are separately labeled diagnostic configurations, never mixed to explain away failure.

## Slice H2 — absolute positions and scoped real interventions

### Exact new H2 API (not existing interfaces)

`GenerationPositionTracker(prompt_length: int, use_cache: bool)` rejects bool/nonpositive lengths and nonbool cache mode. `with tracker.track(model):` installs the root pre-hook with kwargs support and an always-call post-hook; context-finally removes handles and clears active positions even after installation/forward failures. No nested tracking or tracker reuse across generation contexts. A successful root prehook sets `active_positions: tuple[int,...]`, valid only during the root forward; posthook clears it. `tracker.select(values, *, scope, prompt_positions=None)` returns a 1D bool tensor on values.device after validating batch1/sequence length against active positions. A selection outside active root forward always raises, even zero dose. Explicit position tensors must be integer dtype, not cast floats/bools silently; input_ids and inputs_embeds are mutually exclusive. Explicit cache positions can describe chunked prefill; cache-less implicit arange is never used for partial prefill. When cache_position/position_ids are supplied together, every element must match.

`scoped_residual_intervention(model, *, tracker, layer, hook_site, scope, operation, vector=None, dose=1.0, prompt_positions=None, source=None, source_positions=None)` is a context manager yielding a compact diagnostics object with defensive `to_dict()`. hook_site literals `pre`/`mid`/`post` select existing public residual contexts. operation literals `addition`/`ablation`/`replacement`. Consumers nest it inside tracker.track(model); the context validates layer as a genuine nonbool int and never coerces strings/floats. Addition requires finite nonzero vector [d_model], finite real nonbool dose; zero dose returns the exact original tensor after validating dimensions/selection. Ablation requires finite nonzero vector and dose exactly1; no ambiguous scaled ablation. Replacement requires source tensor [1,n_source,d_model] plus unique integer source_positions mapping exactly to selected original prompt_positions, scope='prompt_only', vector=None and dose exactly1. Caller-supplied source is transient and never stored in diagnostics. Select only positions present in current root forward; valid specified positions absent in a chunk are not errors. A copied matching self-source returns original tensor if selected values are torch.equal, without casts/arithmetic. Require matching dtype/device for replacement rather than silently cast; addition/ablation vector may be moved/cast explicitly to hidden dtype/device after finite validation. Reject nonfinite cast or dimension mismatch. Replacement alignment is exact absolute position mapping, independent of source array order; missing/extra mappings rejected up front. No dynamic span matching.

For each hook callback diagnostics aggregate selected token opportunities, changed token count, sum/max of delta L2 norms, finite count and residual-relative delta norms; denominator zero is reported separately rather than infinity. Record layer/site/scope/operation; do not record per-token arrays, source, positions tensor or activations. `scoped_mlp_addition(model, *, tracker, layer, neuron, delta, scope, prompt_positions=None)` wraps the real mlp_addition selector and yields only compact site/scope metadata; native MLP activation diagnostics need not be converted to fake residual deltas. Real residual induced-delta capture for geometry is a separate later slice. tracker root and residual contexts clean up independently and compose through ExitStack if needed. Formal no-op gates still validate actual generation, not these pure transformations alone.

Create `llm_bias/core/inference/stance_interventions.py`, `tests/test_stance_interventions.py`; modify only `mlp_addition.py` and its tests for keyword-only selector support. Consume root HF forward kwargs plus real mlp/residual hooks; produce validated tracker/scopes/scoped operations and reduced diagnostics. Fixtures: tiny root nn.Module with two blocks/dense projections, cached prefill+decode, no-cache prefix recomputation, one-token and multi-chunk explicit prefill, opaque unsupported cache, wrong shapes, root exception; true native addition to one neuron/position, vector addition/ablation/replacement and no-op. Compare hand-set tensors and assert exact unchanged coordinates; no fake that merely reproduces selector formulas. Existing all-position legacy tests stay green. Verify focused new/old MLP and inference tests, full pytest, lock/diff.
