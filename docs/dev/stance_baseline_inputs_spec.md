# Baseline must load the complete immutable input pack

**Goal:** Provide a production input loader for the accepted503-ticker/500-issuer/2012-pair compiler output, with strict byte and semantic checks before any baseline execution. This is the first baseline integration slice, not a model runner or protocol freeze.

Verified `scripts/compile_stance_inputs.py:serialize_inputs` emits population.json (asdict PopulationSnapshot), roles.json (asdict RoleAssignments), evidence_pairs.jsonl (asdict EvidencePair records) and inputs_manifest.json. Manifest output_hashes covers the three payloads; semantic_hashes covers membership, roles and issuer mapping. Current manifest SHA-256 is `b3ee1d47990c9becce37e2eafe4739b9ab1d2544894e3fdfe5febec77819168d`. Compiler checks/immutable publication already passed acceptance; do not edit it or republish the same directory.

Verified reusable validators: `population.validate_members`, `validate_roles`, `assign_roles`; `stance_evidence.validate_evidence_item`, `validate_evidence_pairs`. Population validators accept pure synthetic member fixtures without model checkpoints; production baseline loader cannot accept a smaller cohort. Existing compiler pure fixtures remain unaffected.

In scope: new strict loader and frozen defensive bundle. Later harness must consume this loader without narrowing population.

## 2. Numbered contracts (new design)

**REQ-B0.1 — Pin exact materialization.** `load_baseline_inputs(directory: str|Path) -> BaselineInputs` reads exactly four regular nonsymlink files with the compiler's names; directory itself cannot be symlink. Reject missing/extra files, directories in place of files and changed bytes. Compare raw manifest SHA to the exact approved hash above, then verify all three declared output hashes against raw bytes. Because the approved manifest is pinned, don't accept caller override hashes/counts/config/policies. Historical embedded producer code hashes are provenance, not a requirement that future runtime source hashes equal old compiler code. No model imports. Malformed directory/input raises ValueError or OSError before a consumer can execute.

**REQ-B0.2 — Reconstruct and validate every record.** Strict UTF8 and JSON duplicate-key rejection, no nonfinite JSON constants and exact declared field sets at every parsed object. Enforce canonical sorted-key compact serialization and terminal newline for each complete payload; JSONL no blank lines. Construct known PopulationMember/EvidenceItem/EvidencePair types and compare full semantics, not just counts. Recompute membership hash from sorted member asdict records. Validate503 unique tickers/500 issuers,29 Unspecified sectors. Verify exact issuer mapping and seed20260930 role issuer300/75/25/100/ticker302/75/26/100 using assign_roles and whole roles.json record comparison. Share classes retain the registered FOX/FOXA, GOOG/GOOGL and NWS/NWSA co-location. Approved hashes already bind all evidence text/provenance; validators must still enforce every ticker×factset-20241115-a×four conditions,2012 pairs, exact +-/ -+ full-record swap, required source/review identity and distinct nonempty slots. Importing compiler functions or its config into the reusable core module is not allowed; use core validators and explicit pinned constants where needed. No silent normalization or resorting corrupt serialized inputs to make them pass.

**REQ-B0.3 — Export a deeply immutable input capability.** `BaselineInputs` has read-only properties members:tuple[PopulationMember,...], pairs:tuple[EvidencePair,...], membership_sha256:str, issuer_mapping_sha256:str, roles_sha256:str, evidence_sha256:str (raw JSONL hash), manifest_sha256:str. Provide `roles` and `manifest` properties as defensive JSON dictionary exports plus `issuer_by_ticker:dict[str,str]` defensive export and `pair_for(ticker:str,condition:str,trial_id:str)->EvidencePair` that rejects missing/foreign keys. Store mutable role/manifest data privately as canonical bytes, not a frozen dataclass containing shared dictionaries. Return members/pairs composed of frozen scalar records; reconstruct defensively or store a factory-owned immutable representation if existing frozen records contain nested mutable data. This is an input bundle, not an eligibility proof. It must report manifest eligibility.research_eligible=false unchanged; do not copy a producer note into future result eligibility.
