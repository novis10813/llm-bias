# Generated decision metrics must retain every planned source-class unit

**Goal:** implement P0 Slice 4 outcome-only intention-to-treat (ITT) metrics and paired issuer-cluster uncertainty, without conditioning efficacy on successful intervention decoding.
**Architecture:** pure Python functions consume the frozen execution contracts and return tensor-free defensive JSON dictionaries. No model, pandas, new dependency or research CLI. This supplements REQ-7 in `docs/dev/stance_rebuild_p0_spec.md`.

## Grounding and boundaries

Verified interfaces: `llm_bias/core/experiment_contract.py:ExperimentPlan` has immutable identity, keys and gate names; `validate_rows(plan, rows, require_complete=True)` rejects incomplete, duplicate and foreign rows; `progress` computes declared gate eligibility. `ExecutionRow` has key and outcome; `GenerationOutcome.primary_valid` requires complete schema and reason, legal decision, no failure and successful finish. Failed outcomes clear the primary decision. `tests/test_stance_contract.py:_rows` demonstrates tiny synthetic plans without checkpoints.

New design below is not already implemented. Only create `llm_bias/core/decision_metrics.py` and `tests/test_decision_metrics.py`. Do not modify contracts, prompts, schema, operators, historical artifacts or research protocols. These functions do not decide whether the scientific protocol is valid or supply research bootstrap defaults.

## Numbered contracts

**REQ-M1 — Validate the entire frozen input before computing efficacy.** New API:

```python
summarize_decisions(plan, rows, *, issuer_by_ticker, gates) -> dict
metrics_progress(plan, rows, *, gates=None) -> dict
paired_cluster_bootstrap(plan, rows, *, issuer_by_ticker, gates,
                         stage, condition, direction,
                         left_arm, left_dose, right_arm, right_dose,
                         seed, samples, confidence) -> dict
```

`plan` is ExperimentPlan; rows are an iterable of ExecutionRow; issuer_by_ticker is a mapping of nonblank ticker strings to nonblank issuer strings. Its keys exactly equal all planned tickers; every outcome's issuer_id must match it. Validate even failed outcomes, all stages/conditions/arms, not only a selected bootstrap contrast. Defensive reconstruction must catch mutated/forged typed objects. Gates must exactly match plan.gate_names and be strictly bool; summaries/bootstrap require complete coverage and every declared gate true. A failed or missing gate refuses efficacy. `metrics_progress` permits incomplete coverage and reports only plan hash, planned/executed/missing counts, generation failure counts, complete/eligible and gate state; no decisions, rates, intervals or flips. Malformed, duplicate or foreign rows still fail. Exact progress keys are schema_version=1, plan_hash:str, planned:int, executed:int, missing:int, complete:bool, eligible:bool, gates:dict[str,bool|None], generation_failures:dict[str,int]. Every failure-count dictionary in this module includes all eight canonical experiment_contract failure types with zero defaults and alphabetically sorted keys; do not import a private constant if a documented local tuple is simpler.

Baseline selector is exactly arm='baseline', dose='0'. For each stage, baseline units are (ticker, condition, trial_id). Every stage present in the plan must have a baseline and at least one nonbaseline arm/dose for efficacy; baseline-only stages are allowed only by the progress helper. Every nonbaseline arm/dose present in that stage must cover exactly the baseline unit set, preventing observed-subset alignment. Baseline with another dose, missing/extra paired units or stages without baseline fail. A stage may have a different full population/trial set from another stage, but no arm in that stage may omit a unit. Never pair different stages, conditions or trials. No primary margin/scoring input.

**REQ-M2 — Fixed denominators and distinct directions.** For each sorted (stage, condition, nonbaseline arm, dose), report directions 'buy_to_sell' and 'sell_to_buy' separately. Source class is the first word, target the second. Denominator units are all primary-valid source-class baseline units. An intervention failure contributes zero flips and remains in denominator. For each source unit classify flip, retention (primary-valid same class), or invalid intervention; these counts sum to denominator. Report off-target flips separately (valid baseline opposite class flips towards the source), not as efficacy in the selected direction. Baseline failures are unknown, never source denominator; an observed non-null intervention after baseline failure is not a flip. `observed_flips_over_planned` counts valid class changes in either direction divided by all paired planned units, not a conditional valid-only denominator.

For each ticker k within the condition, d_k is source baseline count, f_k flip count, y_k=f_k/d_k when d_k>0. Primary company-first rate is the unweighted mean of y_k among source-eligible tickers. Secondary micro rate is sum(f_k)/sum(d_k). Return null, not zero/NaN, if source denominator is zero. Explicit counts distinguish source-eligible tickers, source-free tickers, source units and planned ticker/issuer/trial-unit counts. Trials are actual planned units, not count of trial_id strings alone.

**REQ-M3 — Export enough accounting to reconstruct the result.** Summary root keys: schema_version=1, plan_hash, complete=true, eligible=true, gates (defensive copy), issuer_mapping_sha256 (canonical sorted mapping hash), planned_rows, executed_rows, groups (list sorted lexicographically by (stage, condition, arm, dose), with dose compared as its canonical string). Group identity fields: stage, condition, arm, dose. Counts include planned_units, planned_tickers, planned_issuers, distinct_trial_ids, baseline_buy, baseline_sell, baseline_unknown, baseline_primary_valid, intervention_primary_valid, baseline_failures and intervention_failures (failure_type count dictionaries), observed_flips, observed_flips_over_planned. Direction dictionaries under directions have source_units, flips, retentions, invalid_interventions, off_target_flips, source_tickers, source_free_tickers, company_first_rate, micro_rate, and tickers (sorted records {ticker,issuer_id,source_units,flips,rate}; source-free rate=null). All output is finite JSON; exports cannot mutate retained input state. Exact keys above are required; additional compact documented counts permitted only if nonredundant. No text/token/activation serialization.

**REQ-M4 — Resample every planned issuer, with shared draws.** Bootstrap selects two different nonbaseline arm/dose groups with same stage/condition and one direction. Reject absent group, equal selectors, invalid direction, bool/noninteger seed, samples<1 or noninteger/bool, nonfinite/bool confidence or confidence outside (0,1). Use `random.Random(seed)` and sorted planned issuer IDs for that stage/condition. For each draw sample n_issuers occurrences with replacement with rng.randrange(n_issuers), in an explicitly documented draw order. Each issuer occurrence includes ALL its source-eligible ticker rates; share classes remain together, but each ticker retains equal weight in the draw mean. Source-free issuers participate in sampling; they contribute no ticker rate and cannot be removed from the cluster universe. Baseline source eligibility is identical across methods. Draws with no source-eligible ticker are undefined for both methods and difference; record undefined_draws and finite_draws. Do not redraw to conceal undefined draws. Paired difference is left company-first rate minus right, using the very same issuer occurrences, not independent bootstraps. Repeat each ticker's full trial aggregate, never resample trials separately.

Return schema_version=1, plan_hash:str, issuer_mapping_sha256:str, selection identity as seven top-level string fields stage/condition/direction/left_arm/left_dose/right_arm/right_dose, seed:int, samples:int, confidence:float, planned_issuers:int (distinct issuer count), finite_draws:int, undefined_draws:int; left/right/difference each are dictionaries with exactly estimate:float|null and interval:two-number-list|null. If no source exists all estimates/intervals are null, undefined_draws=samples. Percentile endpoints use linear interpolation on sorted finite values at q=(1-confidence)/2 and 1-q, position=(n-1)*q; a single finite draw has identical endpoints. Preserve exact zero paired differences. Do not silently set research seeds/budgets. Future formal protocol will explicitly supply 2,000 draws, confidence=.95 and named preregistered seeds; this module has no implicit defaults.

## Slice M1 is the only writable deliverable

Consumes verified plan/outcome API, produces the three new functions and unit tests. Write failing tests first, run to demonstrate missing module/behavior, then implement and run green. Synthetic fixture contains tickers A1 and A2 of issuer A, plus ticker B of issuer B and ticker C of source-free issuer C; multiple trials and both conditions '+-' and '-+'. One condition hand example: A1 source-buy trials d=1/f=1, A2 d=3/f=0 including one truncated intervention, B d=2/f=1, C baseline unknown. Company-first buy-to-sell rate=(1+0+.5)/3=.5, micro=2/6=1/3. Removing failed intervention must be rejected as missing coverage; treating it as excluded would be incorrect. Include sell-to-buy and opposite condition outcomes to prove separation.

Tests independently enumerate tiny issuer draws or use a hand-specified RNG reference to verify share-class inclusion, source-free issuer participation, company weighting after cluster multiplicity, percentile interpolation, left-right pairing and undefined draws. Reordering rows/mapping/plan input must not change result. Corrupt issuer metadata, gate failures, missing/duplicate/extra keys, wrong baseline dose, mismatched arm coverage and forged typed outcomes must fail before efficacy. Include failure in a nonselected group proving no selected-only validation. Zero source class, one issuer, samples=1, generator input, both source classes, timeout/truncation/reason failure and mutation of returned dictionaries have regressions.
