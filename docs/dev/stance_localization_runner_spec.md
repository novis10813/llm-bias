# LC4 runs complete development localization grids through immutable shards

**Goal:** Put accepted LC0/LC1/LC2/LC3 on real GLM GPUs, without waiting for another baseline. Main implements the runner and tests; code-reviewer and spec-reviewer review before submission. Scope: one script `scripts/run_stance_localization.py` and `tests/test_run_stance_localization.py`; existing modules remain unchanged. All full inputs and baseline parent are validated before CUDA loading; no arbitrary ticker list.

## Fixed stages partition a full pair table, not a smaller input cohort

Build the full4024-pair table from validated503/2012 parent. Development execution uses exactly fit and validation (3016 pairs). Site post, all actual model.layers. Three declared stages: primary has full replacements for all four spans; position has first/middle/last/tail4 for all four spans; alignment_sensitivity has entity full tail_overlap only. Primary/position choose exact_tokens if complete donor/target span tuples equal, relative_rank otherwise, explicitly record each mapping. Layer-sharding uses layer modulo num_shards, not partial company selection. Index genuine0<=i<N and N<=actual layer count. Expected cell count =3016 × assigned layers × declared span/selector count. Completion is shard-local until all N descriptors are merged; do not imply global completion for one shard.

Plan descriptor binds parent content hash, full pair table hash, stage/roles/post/all-layer count, spans/selectors/mapping rule, current model/tokenizer/grammar/head/code/backend/policy records and shard numbers. Hash descriptor including all bindings. Cell key has pair_sha256/layer/span/selector; filename sha256_json(key)+'.json'. No per-cell full-plan hashing. Render all2012 original prompts once, preserving parent wrapper/body/schema; model metadata dictionary must match parent, original resolved GLM path and dtype/cache/policy match. Compile actual grammar; use `_bind_expected` for parent provenance. Runtime/backend/physical GPU/driver recorded, no claim the original baseline bound UUID. Current model remains plain_json; explicit rejection of other channel for this first real runner (LC2 itself supports Harmony).

## Each active layer/span passes a bounded gate before effect cells

For each shard layer and each declared span, take lexicographic first fit/validation baseline key from the full table. Execute actual NO1 baseline/repeat/zero/self on that span at post site, parent policy. Require exact full-output parent match and all NO1 checks true. Store complete four outputs plus scalar diagnostics and config hash as gate_<layer>_<span>.json write-once. This is bounded phase-gate coverage, not proof all prompts are deterministic. Each actual LC2 cell also regenerates clean donor and target and requires full parent equality; mismatch/failure/source-unavailable is written as a halted cell then aborts the shard, never relabeled as flip or eligible completion. Future resume skips recorded failed/halts, but still aborts when encountering them. Intervention failure is an executed no-flip outcome and remains in fixed denominator. Invalid parent pairs, if any, get explicit invalid_parent records without fabricated outputs; current GLM has none.

## Storage reuses an already accepted write-once primitive without rewriting parents

Use recovery_store/publish/read_file from `recover_stance_baseline_truncations.py` for exclusive lock, immutable registration, canonical records and no-overwrite fsync/hardlink publication. A layer-only shard root has registration/store.lock/records; gates are record entries with closed naming, no extra directories. Registration compares exact bytes on resume; reject unexpected/staging/symlink/foreign key files, incomplete initializer, wrong shard or changed identity. On load reconstitute LC2 frozen outputs and mapping from record bytes (do not merely trust status/match_checks), recompute cell key/pair/expected outputs and configuration provenance. Validate diagnostic layer/site and complete cell coverage; parent's expected outputs must match snapshots byte-wise (elapsed/provenance included in stored snapshot integrity). Successful replay diagnostics source coordinates bound by recomputed mapping. Record gates likewise reconstruct NO1 and verify actual expected baseline matches; failed gate aborts. Summary only after exact gate/cell coverage and eligible-generation gate checks: complete_shard true, complete_global only N=1, exact planned/executed/invalid/halted/failure counts and raw toward-source eligible/flip counts by family/contrast/span/layer. Global inferential/selected-sites summaries are a later read-only phase. Research_eligible stays false until global stage completeness and remaining controls/selection/held-out checks; never mutate parent gates.

CLI --model --inputs --parent --output-dir required; --phase primary|position|alignment_sensitivity; --shard-index0 --num-shards1. No max-tokens override (inherit parent), layer/ticker/span filter, old peak or automatic fallback sample. Print compact progress after each cell. Zero direction uses real embedding width/dtype for NO1, no saved residual/tensor. Original TC1 context ensures donor releases every cell. One fresh model per shard; no batched-generation equivalence claim.

## Acceptance is fake-model first, then real full-manifest gate execution

Tests cover closed CLI, stage enumeration/all-roles descriptors, sharding exact coverage, cell key filename, full outputs/mapping re-import, parent drift abort vs failed intervention counted/no retry, malformed record/gate/foreign files/staging and summary coverage, zero schema/unknown preserve honest status. Use tiny fake helper inputs for internal stage iterators only; public runner always validated full parent. No checkpoint in pytest. Main tests + both reviewer reports + lock/diff precede code push; full regression runs background. Real GLM run begins as declared primary stage, performs gates before effects; if gates or runtime fail retain errors and report, not auto-rerun invalid effects.
