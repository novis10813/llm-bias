# Entity Cell：單一神經元影響部分公司知識，未讓受測買賣決策翻轉

**狀態：已收線（主線）。** 模型為 Qwen3.5-4B；V3 事實判定已凍結，E4 為已執行的診斷，E5 仍是未執行提案。

**一句話發現：** 干預單一神經元會降低模型回答某家公司部分事實的機率，也發現多家公司共用的事實通道；這不等於完全忘記公司，事實受損也未使受測買賣決策翻轉。

## 1. 單一神經元能讓模型忘記整家公司嗎？目前只支持部分事實受影響

我們想驗證「找到對公司名稱有反應的神經元後，干預它是否會破壞該公司的知識」。先用不同自然句定位候選，再問總部、股票代號與成立年份，比較干預前後答案機率，以及干預其他公司候選、同層隨機神經元的對照。

方法改編自 [V2 文獻對照](details/proposal-v2.md) 所列的 Barzilay et al.（2026）；本 repo 的句框數與表面控制不同，不把本線結果直接當成對原論文所有設定的復現或反證。

這裡的「壓制」不是一律關掉神經元：**V3 事實測試在所有輸入位置把該 MLP 通道的激活乘以 −3，也就是反向並放大；乘以 0 才是歸零。** 評分固定使用正常模型以 greedy 解碼生成、經人工驗核的前三個 token 序列，測量其聯合對數機率變化；答案前綴不一定涵蓋完整事實，未通過驗核的題目不納入 V3 判定。下表負值表示原答案機率降低，不直接等於知識遭到永久刪除；所有數值單位均為 nats。

| V3 確認的公司／神經元 | 總部 | 股票代號 | 成立年份 |
|---|---|---|---|
| JNJ（L4/N7676） | −8.51 | −0.74 | −4.49 |
| BAC（L0/N7801） | −7.77 | −7.84 | +0.44（E4 記錄；答案有效性見下） |
| CAT（L2/N7997） | 正常回答不適用，未納入 | −3.49 | 正常答案錯誤，未納入 |
| PLTR（L2/N5003） | +0.15 | 通過下降至少 0.5 的門檻 | 此彙整未列數值 |

**觀察：** BAC 的總部與代號答案機率大幅下降；JNJ 的總部、年份受影響較大，代號也下降但幅度較小。正常模型答不對的題目不能用來判斷「遺忘」，因此 CAT 的空缺不是沒有影響的證據。

**來源差異：** E4 記錄 BAC 年份答案機率增加 0.44，但後續 [E5 正常回答檢查 §3.4](details/proposal-e5.md) 將 BAC 年份列為答案錯誤、不可用；本報告保留兩者，不把這個數值當成「正確年份知識保留」的證據，答案有效性仍須查核。

**解讀：** V3 在校準與新公司驗證兩批中共確認上述四個單元符合判準；它們影響的是受測事實子集，不能概括成每家公司有一個儲存全部知識的神經元。

來源：[V3 協議 §3–4、§9–10](details/proposal-v3.md) 記錄方法、校準數值與正式驗收；[E4 報告](details/report-e4-readout-delta.md) 補充 BAC 年份與 PLTR 總部的輸出變化。數值跨校準探針與後續量測彙整，不是單一批次的新實驗。

## 2. 一個神經元只影響一家公司嗎？受測範圍內有共享通道

**觀察：** V3 的跨公司測試中，干預 L0/N3 會降低九家公司總部答案的機率；L0/N4485 也在跨公司檢查中影響 INTC、QCOM、V、XOM。依 V3 定義，這類單元稱為 **shared fact channel（共享事實通道）**，不列為公司專屬單元。

**解讀：** 對某家公司有強反應，並不足以判定神經元只服務那家公司；但多家公司受影響，也不能直接證明它是共同的「知識儲存槽」或唯一檢索機制。

「未發現共享」同樣有範圍限制：正式交叉檢查只涵蓋同批公司的總部題，並未測遍所有公司與事實。四個 V3 單元的專屬性只在這套檢查內成立。完整共享通道與分類見 [V3 §5、§10](details/proposal-v3.md)。

## 3. 事實答案受損，買賣決策就會改變嗎？未翻轉，但傾向並非完全不變

此處用固定 buy 與 sell 答案的 logit 差衡量買賣傾向，差值跨過零才算決策翻轉。

**觀察：** JNJ/JPM 決策探針未出現買賣翻轉，部分提示的買入傾向反而增加，沒有如原假設般靠近匿名公司的回答。JNJ 的 E3 上游測試共 108 筆紀錄，也沒有翻轉；對選出的五個晚層注意力頭做來源成分衰減，買賣傾向的變化約在 ±0.03 nats 內。

這 **108 筆屬於 JNJ，不是四個 V3 單元各自都做過同樣驗證**。JNJ 的候選選擇當時屬 proposed 延伸，不能寫成依凍結 V3 名冊完成的正式 E3 確認。來源：[JNJ/JPM 測試 §1、§3–4、§6](details/report-jnj-jpm-battery.md)。

另有不能省略的早期結果：FTNT 的 L0/N104 在修正計分儀器後，仍通過原 E3 V1 的特異性判準，平均買入傾向向匿名基準靠近，但沒有決策翻轉，且不同提示的移動方向不全一致。這是早期候選的結果，不是 V3 四個單元的驗證。來源：[E3 V1 儀器重驗 §6](details/report-e3-v1.md)。

**解讀：** 本線沒有支持「破壞公司事實，就能消除該公司的投資偏好」這個簡單假設；也不能把零翻轉寫成零效應，或據此排除其他神經元組合與下游路徑。

## 4. 中間層讀出改變，不足以確定知識如何儲存或修復

E4 診斷用 Jacobian lens 比較干預前後的逐層詞彙讀出：某些差異在候選所在層之後才明顯出現，JNJ 總部題的高排名城市詞也改變；BAC 年份與 PLTR 總部題即使最終答案機率沒有下降，中間層讀出仍有變化。

這些是**干預後的表徵觀察**。讀不出公司詞，不等於該層沒有公司資訊；候選詞改變，也不足以證明模型用另一段記憶替換原知識，或已定位到後續修復機制。Lens 分數與真實輸出機率不能直接比較大小。來源與完整結果見 [E4 報告](details/report-e4-readout-delta.md)；此診斷不新增 V3 認證。

## 5. 方法曾改變，但各版本結果仍分開保留

V1 的固定 header 定位讓許多公司撞到同一候選，無法排除格式反應；V2 改用自然句，但仍要求干預後決策靠近匿名基準。事實測試與決策測試的落差，促使 V3 改以事實答案受損及跨公司對照判定，**不再把決策移動當作確認事實單元的必要條件**。

這是版本間的研究問題修正，不回頭改判 V1/V2。V3 校準與新公司驗證合計 22 家，除了四個確認單元，其餘包含共享通道、未通過句式穩健性的候選、未達事實門檻及正常答案無法驗核者；未通過不等於模型沒有該公司的知識。

主線維持收線。交易所、競爭對手與其他句框的干預仍列在 [E5 提案](details/proposal-e5.md)；已做正常回答的可用性檢查，不代表干預已執行或獲得新結果。本報告不授權後續 run。
